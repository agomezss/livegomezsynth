## Locked (Owner)

| ID   | Decision                                                                                                                                                                                                                                                       |
| ---- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-01 | Name: **LiveGomezSynth**. Flash data family string: `LIVEGMZ` (7 chars max in the SMKSYNTH owner-tag scheme).                                                                                                                                                  |
| D-02 | Base: code taken from `SMKSYNTH` (~90%), **not a fork** (D-52). `smk37_open` = documentation and best practices. `clipper-smk` = engine donor.                                                                                                                 |
| D-03 | **Knob layout (as SMKSYNTH 1.2.0 already has it, T0.4):** K1-K4 = 4 patch parameters, K5-K7 = navigation, K8 = MASTER volume (endless virtual pot: 24 steps of 1024 per detent, default ~70%; SMKSYNTH also saves it at manual store and restores it at boot). |
| D-04 | **Pads:** favorites in PATCH and PERFORM modes. (SEQ is removed, D-50.) When a Drums-category patch is loaded, the pads play drum hits (see D-12 for how favorites stay reachable).                                                                            |
| D-05 | **Solo:** while SOLO 1/2 is active, LAYER 1/2 are muted and the whole keyboard plays the solo line. Leaving solo restores the layers.                                                                                                                          |
| D-06 | **Faders** are always the 4 FX sends (CHORUS, DELAY, DIST, REVERB). In PATCH they act on the current patch; in PERFORM on the active line (last played / being edited).                                                                                        |
| D-07 | **Tweaks (K1-K4)** are temporary: loading another patch resets them. Only a favorite saves a snapshot including tweaks.                                                                                                                                        |
| D-08 | **Phasing:** M0 technical spike -> M1 framework + UI + simulator with ~64 patches -> M2 extra engines -> M3 live core catalog.                                                                                                                                 |
| D-09 | Owner has the device; the full flash backup is pending (superseded by D-48 / P-01).                                                                                                                                                                            |
| D-10 | Docs in English, UI strings in English, license GPL-3.0-only.                                                                                                                                                                                                  |

## Fixed by IDEA.md (not up for debate unless the owner says so)

| ID   | Decision                                                                                                                                                                                                                            |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D-20 | ARP, CHORD, GLOBAL behave exactly as in SMKSYNTH (reuse code untouched where possible). SEQ is removed (D-50).                                                                                                                      |
| D-21 | PATCH mode: 16 favorite pads, bank A-D (KNOB BANK cycles), arrows change category. Hold pad = save prompt (5 s, confirm by pressing the same pad, "saved successfully" for 2 s).                                                    |
| D-22 | PERFORM mode: 14 combo pads (pads 1-7 and 9-15) + pad 8 = SOLO 1 + pad 16 = SOLO 2. Banks A-H (FADER BANK cycles).                                                                                                                  |

| D-24 | KNOB BANK -> always goes to PATCH. FADER BANK -> always goes to PERFORM. KNOB BANK + FADER BANK together in PERFORM -> EDIT mode. Performance can only be modified in EDIT mode.                                                    |
| D-25 | 16 categories (01 Favorites .. 15 Drums, 16 ICONIC in the slot of the removed GM, D-51/D-53); pads 1-16 in EDIT mode preselect the first patch of each category for the selected line.                                                              |
| D-26 | Patch numbers are immutable. Favorites are shown with an `F` prefix (F001..F064).                                                                                                                                                   |
| D-27 | Engines: FM (majority), SYN (existing OberVave engine), SP (sampler), ORG (organ). Optional prefixes FM2, DRM and generic analog-flavor prefixes (D-42; see 05). Same timbre may exist in several engines, distinguished by prefix. |
| D-28 | A browser simulator is mandatory and gates any hardware work.                                                                                                                                                                       |
| D-29 | Brick-avoidance rules (06) are non-negotiable.                                                                                                                                                                                      |

## Derived (spec author, challengeable)

| ID   | Decision                                                                                                                                                                                                                                | Rationale                                                                           |
| ---- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| D-30 | Parts: LAYER 1 = part A, LAYER 2 = part B, SOLO 1 = part C, SOLO 2 = part D (NPART=4).                                                                                                                                                  | SMKSYNTH already has exactly 4 parts and a multi-engine table (`obv_engine_ops_t`). |
| D-31 | Performance line stores a **snapshot copy** (patch ID + tweaks + sends + range + flags), not a live reference to a favorite slot. The `F` prefix is an origin flag shown at selection time.                                             | A later favorite overwrite must never silently alter a saved live setup.            |
| D-32 | Patch IDs are fixed-block per category (32 slots each) so IDs never shift when patches are added. Display numbers in `IDEA.md` are illustrative.                                                                                        | Satisfies "immutable". See 04.                                                      |
| D-33 | FM engine = Clipper `FM6` (msfa, Apache-2.0, Felucca-compatible) rather than the `smk37_open` copy. Both are msfa; the Clipper one already fits the engine interface family.                                                            | Lower port risk. Cross-check against `smk37_open/third_party` in T2.1.              |
| D-34 | `FM2` = Clipper `DIGITAL` (4-op, 8 algorithms). `FMX` (6-op routable) deferred (CPU High).                                                                                                                                              | Distinct from DX7-style FM and Juno. See 05.                                        |
| D-35 | Analog flavors (prefixes `SVF`, `PLY`, `LAD`) start as **flavors** (parameter sets / filter models) of SYN and Clipper `ANALOG`. Dedicated engines only if time allows.                                                                 | Avoids new DSP work in the focus-critical milestone.                                |
| D-36 | Edit mode commits via an explicit prompt on exit (pad 1 blue = save, pad 2 red = discard).                                                                                                                                              | Consistent with the search popup UI; prevents live accidents.                       |
| D-37 | KNOB BANK long-press (700 ms) keeps SMKSYNTH's panel check. Chord (KNOB BANK + FADER BANK) is detected by a 120 ms window and suppresses the single-press mode switch.                                                                  | Preserves a debugging tool; defines chord timing.                                   |
| D-38 | Packages use a new identity and data family, never SMKSYNTH's `OBERVAV`. First boot with a foreign tag clears only the app's own settings sectors (as SMKSYNTH does). Installer docs must warn the user to back up SMKSYNTH data first. | Cross-contamination avoidance.                                                      |
| D-39 | Range model: each line stores a **low octave** and a **high octave** (both editable, D-14). A line sounds notes from C of the low octave through B of the high octave; display `(Clo-Chi)`. See 03 section 6.                           | `IDEA.md` asks for a lower octave knob; the owner added the upper octave knob.      |
